# ZalupAI Bot

Telegram бот для расшифровки голосовых сообщений и озвучки текста.

## Возможности

- **Расшифровка голосовых** — конвертирует голосовые сообщения и кружочки в текст **с пунктуацией**
- **Озвучка текста** — превращает текст в голосовое сообщение (голос диктора)
- Работает в групповых чатах и личных сообщениях
- Полностью бесплатно и офлайн (Whisper + Silero TTS)
- Высокое качество распознавания русского языка

## Быстрый старт

### 1. Получите токен бота

1. Напишите [@BotFather](https://t.me/BotFather) в Telegram
2. Создайте нового бота командой `/newbot`
3. Скопируйте полученный токен

### 2. Настройте переменные окружения

```bash
cp .env.example .env
# Отредактируйте .env и вставьте ваш токен
```

### 3. Запустите через Docker

```bash
docker-compose up -d --build
```

### 4. Настройте права бота (ВАЖНО!)

**Боты по умолчанию не видят сообщения в группах!** Нужно сделать одно из двух:

**Вариант A: Отключить Privacy Mode (рекомендуется)**
1. Напишите [@BotFather](https://t.me/BotFather)
2. `/mybots` → выберите вашего бота
3. `Bot Settings` → `Group Privacy` → `Turn off`

**Вариант B: Сделать бота админом**
- Назначьте бота администратором группы

### 5. Добавьте бота в чат

1. Добавьте бота в групповой чат
2. Отправьте голосовое сообщение — бот автоматически расшифрует его

## Использование

### Расшифровка голосовых
Просто отправьте голосовое сообщение или кружочек — бот автоматически расшифрует с пунктуацией.

Формат ответа:
```
🎙 Голосовой эфир от пользователя (Имя Фамилия) 14:30:25

Привет, как дела? Я сегодня ходил в магазин, купил хлеб и молоко.
```

### Озвучка текста

**Способ 1:** Ответьте на текстовое сообщение с упоминанием бота
```
@yourbot
```

**Способ 2:** Перешлите текстовое сообщение и упомяните бота
```
[пересланное сообщение]
@yourbot
```

**Способ 3:** Команда `/voice`
```
/voice Привет, это тестовое сообщение!
```

## Настройка модели Whisper

Доступные модели (переменная `WHISPER_MODEL` в `.env`):

| Модель | Размер | Скорость | Качество |
|--------|--------|----------|----------|
| `tiny` | ~75MB | Очень быстро | Базовое |
| `base` | ~150MB | Быстро | Хорошее |
| `small` | ~500MB | Средне | Очень хорошее (по умолчанию) |
| `medium` | ~1.5GB | Медленно | Отличное |
| `large-v3` | ~3GB | Очень медленно | Максимальное |

## Настройка голоса TTS

Доступные голоса (переменная `TTS_SPEAKER` в `.env`):

| Голос | Пол | Описание |
|-------|-----|----------|
| `xenia` | Женский | По умолчанию, нейтральный |
| `aidar` | Мужской | Низкий голос |
| `baya` | Женский | Мягкий голос |
| `kseniya` | Женский | Выразительный |
| `eugene` | Мужской | Нейтральный |

## Команды бота

- `/start` — Приветственное сообщение и инструкции
- `/voice <текст>` — Озвучить текст

## Логи

```bash
docker-compose logs -f zalupaibot
```

## Технологии

- **Whisper (faster-whisper)** — распознавание речи с пунктуацией
- **Silero TTS** — офлайн синтез речи
- **aiogram 3** — асинхронный Telegram Bot API
- **FFmpeg** — конвертация аудио

## Требования

- Docker и Docker Compose
- Telegram Bot Token
- ~3GB RAM (для моделей small + TTS)
