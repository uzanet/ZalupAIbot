# ZalupAI Bot

Telegram бот для автоматической расшифровки голосовых сообщений в текст.

## Возможности

- Автоматическая расшифровка голосовых сообщений
- Расшифровка видеосообщений (кружочков)
- Работает в групповых чатах и личных сообщениях
- Бесплатное офлайн распознавание русской речи через Vosk
- Формат ответа: `Голосовой эфир от пользователя (Имя Фамилия) ЧЧ:ММ:СС - текст`

## Быстрый старт

### 1. Получите токен бота

1. Напишите [@BotFather](https://t.me/BotFather) в Telegram
2. Создайте нового бота командой `/newbot`
3. Скопируйте полученный токен

### 2. Настройте переменные окружения

```bash
cp .env.example .env
# Отредактируйте .env и вставьте ваш токен
```

### 3. Запустите через Docker

```bash
docker-compose up -d --build
```

### 4. Настройте права бота (ВАЖНО!)

**Боты по умолчанию не видят сообщения в группах!** Нужно сделать одно из двух:

**Вариант A: Отключить Privacy Mode (рекомендуется)**
1. Напишите [@BotFather](https://t.me/BotFather)
2. `/mybots` → выберите вашего бота
3. `Bot Settings` → `Group Privacy` → `Turn off`

**Вариант B: Сделать бота админом**
- Назначьте бота администратором группы

### 5. Добавьте бота в чат

1. Добавьте бота в групповой чат
2. Отправьте голосовое сообщение - бот автоматически расшифрует его

## Улучшение качества распознавания

По умолчанию используется маленькая модель Vosk (~45MB). Для лучшего качества можно подключить большую модель:

```bash
# Скачайте большую модель (~1.8GB)
wget https://alphacephei.com/vosk/models/vosk-model-ru-0.42.zip
unzip vosk-model-ru-0.42.zip

# Раскомментируйте volumes в docker-compose.yml и перезапустите
docker-compose up -d --build
```
